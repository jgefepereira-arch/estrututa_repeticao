# 📊 **Pesquisa de Satisfação**

Este projeto foi desenvolvido para **automatizar** a coleta e análise da pesquisa de opinião e satisfação de até **50 clientes da empresa TudoWeb**.

## 🛠️ Funcionalidades

- **Coleta de dados**: Solicita nome, idade e a nota de avaliação do cliente.
- **Métrica de coleta**: As avaliações variam de 1 a 4, sendo 1 = **EXCELENTE**; 2 = **BOM**; 3 = **RUIM**.
- Ao final compila a quantidade de avaliações "**EXCELENTE**" e "**RUIM**".
